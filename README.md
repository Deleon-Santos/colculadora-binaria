# Calculadora de numeros Binários, Decimais e Hexadecimais

Aplicação desenvolvida para facilitar o entendimento e ajudar nas atividades de matemática aplicada à computação. Usando Python e seus recursos além de interface grafica foi possivel desenvolver uma aplicação que facilita a conversao de valores.

## Funcionalidades

1. Converter binário para decimal
2. Converter decimal para binário
3. Converter hexadecimal para decimal
4. Converter decimal para hexadecimal

## Pré-requisitos

- Python 3.x instalado
- Conhecimento básico em execução de scripts Python
